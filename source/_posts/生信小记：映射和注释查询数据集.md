在前面的教程中，我们比较系统地学习了处理单细胞测序数据的分析流程。分析流程严谨而精细，可以帮助我们获得很多有价值的信息。然而，对于长期专注于某一领域的研究者来说，每拿到一批数据都要走一遍这样的分析流程，其计算量大、耗费的时间精力多、效率低下，不太能满足研究者的效率需求。为了提高效率，研究者们开辟出了一条更为方便的捷径，即使用多个可靠的数据集构建一个整合的参考框架，在拿到新的数据之后不再需要从头开始分析，只需要通过算法将数据映射到参考数据集上，即可自动获得较高质量的注释。这个过程很像人工智能大模型的开发，即使用高质量的标注标注数据​“训练”​​一个模型，学习其中的模式、特征和关联，让其获得充分的知识储备和逻辑分析能力，在遇到新问题时可以利用内部知识进行推理并生成答案。

# 数据集的预处理

我们先引入示例数据集，这份数据集包括由四种不同测序技术得到的人胰岛细胞数据，即CelSeq（GSE81076）、CelSeq2（GSE85241）、Fluidigm C1（GSE86469）和SMART-Seq2（E-MTAB-5061）。

# 使用参考数据集对细胞进行分类
Seurat可以将参考数据集的结构和信息映射到我们所分析的数据集上。这就好比将新的卫星拍摄的俯瞰图重叠在一张已有的、做好标注的图片上，从而快速识别新图片中的信息和变化。

Seurat的映射功能具有以下两个值得注意的特征：
- **不改变原数据集的信息。** 在数据的映射过程中，Seurat只会对所处理的数据集的细胞信息进行标记和注释，不会对其进行纠正或篡改。
- **默认使用PCA降维结果进行映射，而不使用CCA。** 我们现在的目的是注释和标记，而不是将参考数据集和待分析的数据集进行比较，因此不需要使用CCA降维消除批次效应。CCA算法消除批次效应的本质是让两个数据集相互“妥协”和“对齐”，这势必会对两个数据集的原始信息发生改变，削弱了参考数据集的权威性，也破坏了待分析数据集的真实性——这绝对是我们不愿见到的。

我们将映射后，待分析数据集和参考数据集之间生物学状态相对应的“细胞对”称为 **锚点（archor）** 。通过`FindTransferAnchors()`函数，我们得以找到不同数据集之间的锚点。在这之后，我们可以利用`TransferData()`函数进行数据标记的转移，也就是以参考数据集为参考，对待分析的数据集的细胞进行标记。`TransferData()`函数的运行结果是一个包括了各个细胞的预测细胞类型和预测的相似度的矩阵（表格），我们可以使用`AddMetaData()`函数将其加入到待分析数据集中，从而实现细胞的标注。

```R
pancreas.query <- subset(panc8, tech %in% c("fluidigmc1", "celseq"))
pancreas.query <- NormalizeData(pancreas.query)
pancreas.anchors <- FindTransferAnchors(reference = pancreas.ref, query = pancreas.query, dims = 1:30,
                                        reference.reduction = "pca")
predictions <- TransferData(anchorset = pancreas.anchors, refdata = pancreas.ref$celltype, dims = 1:30)
pancreas.query <- AddMetaData(pancreas.query, metadata = predictions)
```

到这里，我们的映射和注释工作就完成了。但是还有一个问题：映射的准确度怎么样？所得到的结果能不能让人信服？刚好，我们的数据包里存储了各个细胞的准确细胞类型，我们可以来对比对比：

```R
pancreas.query$prediction.match <- pancreas.query$predicted.id == pancreas.query$celltype
table(pancreas.query$prediction.match)
```

- 运行结果：

# UMAP映射
当我们有一个准确的UMAP参考数据框架时，我们可以直接将待分析数据集映射在参考UMAP框架上，从而实现快速标记和注释。这一过程主要是通过`MapQuery()`函数实现的。在这之后，我们可以将参考数据集和待分析数据集一起可视化。

```
pancreas.ref <- RunUMAP(pancreas.ref, dims = 1:30, reduction = "integrated.cca", return.model = TRUE)
pancreas.query <- MapQuery(anchorset = pancreas.anchors, reference = pancreas.ref, query = pancreas.query,
    refdata = list(celltype = "celltype"), reference.reduction = "pca", reduction.model = "umap")
p1 <- DimPlot(pancreas.ref, reduction = "umap", group.by = "celltype", label = TRUE, label.size = 3,
    repel = TRUE) + NoLegend() + ggtitle("Reference annotations")
p2 <- DimPlot(pancreas.query, reduction = "ref.umap", group.by = "predicted.celltype", label = TRUE,
    label.size = 3, repel = TRUE) + NoLegend() + ggtitle("Query transferred labels")
p1 + p2
```
> 参数 reference.reduction = "pca"指定了参考数据集用于计算锚点的降维空间（这里是原始PCA）。这与前面 FindTransferAnchors时使用的 reference.reduction = "pca"是一致的。
