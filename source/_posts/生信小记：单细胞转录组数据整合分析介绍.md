整合多组单细胞测序数据集（如跨实验批次、供体或条件），是scRNA-seq的重要步骤之一。整合分析可以匹配不同细胞集之间相同的细胞类型和细胞状态，提高统计效能，有利于跨数据集的准确比较分析。本篇文章将对利用Seurat集成分析进行复杂细胞类型间的比较分析进行简要概述。我们进行比较分析的主要目的主要在于以下三点：
1. 确认在不同细胞数据集中均存在的细胞簇；
2. 确认在实验组（经过某种特定刺激）和对照组中保守的细胞类型标记；
3. 对比并确认细胞对该刺激所作出的特定反应。

# 创建Seurat对象
首先我们安装并加载所需要的R包，并通过`SeuratData`包下载本篇文章所需要的原始数据。这份数据包括以下两组细胞：①经干扰素刺激的人PBMC细胞；②对照组人PBMC细胞。在接下来的分析中，整合上述两组细胞数据集，以识别共同的细胞亚群并比较其在不同处理条件下的差异。

> 实操过程中，由于网络情况及文件大小等原因，可能会出现因超时而导致下载中止并报错的情况。在安装数据之前运行`options(timeout=10000)`，将超时限制放宽即可正常下载。

```
library(Seurat)
library(SeuratData)
library(patchwork)
options(timeout=10000)
InstallData("ifnb")
```

# 进行不整合的简单分析
为了更直观地感受分别分析给两组比较带来的挑战，我们先用传统的方法对两组数据分别进行单独分析。从得到的UMAP图上我们很容易看到，两个数据集所分出的细胞簇总数超级多，这是因为两个数据集中每一种类型的细胞都按照数据集的类型被分为两类，而没有整合为一类细胞。这很显然对我们对比分析两组细胞不太有利。
```
ifnb <- NormalizeData(ifnb)
ifnb <- FindVariableFeatures(ifnb)
ifnb <- ScaleData(ifnb)
ifnb <- RunPCA(ifnb)
ifnb <- FindNeighbors(ifnb, dims = 1:30, reduction = "pca")
ifnb <- FindClusters(ifnb, resolution = 2, cluster.name = "unintegrated_clusters")
ifnb <- RunUMAP(ifnb, dims = 1:30, reduction = "pca", reduction.name = "umap.unintegrated")
DimPlot(ifnb, reduction = "umap.unintegrated", group.by = c("stim", "seurat_clusters"))
```

# 整合两组数据集（CCA降维）
利用`IntegrateLayer()`函数，可以通过典型相关分析（CCA），识别共享或同源基因来确定共享细胞类型或状态（也就是在不同组别中共享的细胞类型），进而建立跨数据集的关联，从而实现两组数据的整合。这一过程不会消除不同组别细胞之间基因表达的生物学差异，因此不会影响组间分析。整合后的数据将会存放在一个低维嵌入空间（`integrated.cca`）中。

此时两组数据仍然存储在两层中，因此我们使用`JoinLayer()`函数合并两组数据，该过程将会覆盖原始分层存储的数据。

随后，我们对CCA降维后的数据进行细胞聚类和UMAP降维。
```
ifnb <- IntegrateLayers(object = ifnb, method = CCAIntegration, orig.reduction = "pca", new.reduction = "integrated.cca", verbose = FALSE)
ifnb[["RNA"]] <- JoinLayers(ifnb[["RNA"]])

ifnb <- FindNeighbors(ifnb, reduction = "integrated.cca", dims = 1:30)
ifnb <- FindClusters(ifnb, resolution = 1)
ifnb <- RunUMAP(ifnb, dims = 1:30, reduction = "integrated.cca")
```

随后我们可以进行可视化。下图中左图为按照实验条件分组的图像，右图为按照CCA整合后聚类的人工注释结果分类的图像。
```

```

# 识别保守的细胞类型标记
`FindConservedMarker()`函数，人如其名，可以帮助我们识别在不同处理条件下同一类型细胞中不随处理条件变化的稳定标记基因。其原理为：①在每个实验条件中，分别比较目标细胞群与其他所有细胞的差异表达基因，并计算每个条件的$p$值和表达量；②使用MadeDE包中的​元分析，将不同实验条件的统计值（如$p$值）合并，得到​跨条件统一的显著性评估。

以下述代码为例，我们确认了细胞簇6（即NK细胞）的保守标记基因。
```
install.packages('BiocManager')
BiocManager::install('multtest')
install.packages('metap')

nk.markers <- FindConservedMarkers(ifnb, ident.1 = "NK", grouping.var = "stim", verbose = FALSE)
head(nk.markers)

# 识别不同处理条件下细胞的差异表达基因

这一步我们将分析出在不同处理条件下，在同一细胞类型中表达存在显著差异的基因。但在这之前，我们需要把现在的数据转化为“伪批量”数据。这是因为，在单细胞测序中，单个细胞的基因表达量差异很大，某个基因可以在某个或某些细胞偶然性地高表达或低表达，这和细胞环境及所受刺激没有直接关联。伪批量（pseudo-bulk）是将同一实验条件下同一类型的多个细胞数据合并并计算的平均值。伪批量的稳定性和可靠性较原始数据（这里指没有转化为伪批量的数据）强，更容易发现不同刺激条件下基因表达的差异。

下面代码将以CD4 Naive T cells和CD14 Monocyte为例进行比较。如下图所示，很多相同的、可能与干扰素保守反应途径相关的基因在这两种细胞中都被上调，尽管CD14 Monocyte的转录水平差异更大。

```
library(ggplot2)
library(cowplot)
theme_set(theme_cowplot())

aggregate_ifnb <- AggregateExpression(ifnb, group.by = c("seurat_annotations", "stim"), return.seurat = TRUE)
genes.to.label = c("ISG15", "LY6E", "IFI6", "ISG20", "MX1", "IFIT2", "IFIT1", "CXCL10", "CCL8")

p1 <- CellScatter(aggregate_ifnb, "CD14 Mono_CTRL", "CD14 Mono_STIM", highlight = genes.to.label)
p2 <- LabelPoints(plot = p1, points = genes.to.label, repel = TRUE)

答案是可以的。在这里，我们在meta.data这个"槽"中新建一列用以存储细胞类型和存储信息，然后将`ident`（默认分组标识）切换到这个列；也就是告诉机器，细胞按照这个标准分组。然后我们就可以上`FindMarkers()`函数啦，这样就可以区分出不同刺激条件下的差异表达基因。
```
ifnb$celltype.stim <- paste(ifnb$seurat_annotations, ifnb$stim, sep = "_")
# 将每个细胞的所属细胞类型和处理条件合并、并用“_”分开，从而进行重新分组，比如刺激组的B细胞将会重新分组为“B_STIM”。
Idents(ifnb) <- "celltype.stim"
# 将Seurat对象的默认分组标识（Idents）设为新生成的celltype.stim列。
b.interferon.response <- FindMarkers(ifnb, ident.1 = "B_STIM", ident.2 = "B_CTRL", verbose = FALSE)
# 相对于对照组的B细胞，寻找刺激组的B细胞的差异表达基因
head(b.interferon.response, n = 15)
# 显示前15个差异表达基因
```

我们需要注意的是，在解释上述结果中所显示的$p$值要慎之又慎。原因主要在于忽略了各个细胞间的共同来源性（非独立性）。同一批次的各个细胞之间的遗传背景、环境暴露等因素相同或类似，且存在相互影响。而在统计学分析过程中，则默认每个细胞对于刺激所作出的反应是独立的。讲人话就是，假设有样本A、B各1000个细胞，如果我们直接将2000个细胞作为独立的“观测值”，分析时程序会误认为有2000个样本（但实质上只有A和B两个样本）。由于同一样本的细胞间变异通常小于样本间细胞的变异性，此时变异性会被稀释，从而导致更容易得到统计差异显著的结果，也就是“假阳性”。

如何解决上述问题呢？答案就是伪批量分析。通过计算样本内所有基因表达量的平均值，将同一样本内的多个细胞合并为“一个”细胞，最后在比较时就是两个“细胞”之间的比较啦！就可以顺利地解决问题！
