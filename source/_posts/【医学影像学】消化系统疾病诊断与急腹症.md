# 急腹症
## 急腹症常用的影像学检查方法：
### X线
#### X线平片及透视
1、X线平片：至少要求：站立正、仰卧前后位。其它：侧位、仰卧水平侧位、侧卧水平正位、倒立正、侧位。

2、透视（现少用）：除可观察病变外，还可动态观察膈肌运动和胃肠蠕动

#### 造影检查
较少在急性期使用，多用于寻找病因。
- 钡剂或空气灌肠：肠套叠、扭转、结肠癌
- 钡餐：先天性幽门肥厚、十二指肠梗阻
- 泛影葡胺：上消化道出血、穿孔及肠梗阻
- PTC（经皮肝穿胆管造影）：胆管梗阻
- 静脉肾盂造影：尿路外伤
- 选择性或超选择性血管造影：急性消化道大出血

### CT检查：平扫与增强扫描

## 正常表现
- 腹壁与盆壁：腹膜后、肾周脂肪呈灰黑影，胁腹线
- 腰大肌、腰方肌、闭孔内肌、提肛肌
- 骨性结构
- 实质器官：肝、脾、胰、肾、子宫
- 空腔器官：胃肠道、胆囊、膀胱

## 基本病变的X线表现
### 胃肠道内异常气体
空腔器官积气积液，并管腔扩大（可判断肠管位置、活动度变化）
- 不同肠段胀气表现
    - 空肠：肠腔内环状皱襞密集
    - 回肠起始段：肠腔内较多环状皱襞
    - 回肠末段：肠腔内不见环状皱襞
    - 结肠：可见结肠袋的间隔

![](/images/yx_xiaohua/图片2.png)
|  | 空肠 | 回肠 | 结肠 |
| :----------: | :----------: | :----------: | :----------: |
| 部位 | 左上腹 | 右下腹及盆腔 | 腹周 |
| 大小 | ＞3cm | 略小 | ＞5~7cm |
| 黏膜 | 多环状、贯肠腔 | 无 | 少、不贯肠腔 |

## 消化道穿孔与腹膜炎
### 病因
溃疡、外伤、炎症、肿瘤，以胃、球溃疡穿孔最常见
### 病理
穿孔后气体和内容物进入腹腔，出现气腹及腹膜炎
### X线表现
- 游离气腹：最重要、最早出现
- 腹脂线异常
- 麻痹性肠胀气

## 肠梗阻
### 分类
- 机械性：单纯性、绞窄性
- 动力性：麻痹性、痉挛性
- 血运性：血栓形成或栓塞
### X线检查目的
a.有无梗阻；b.梗阻部位；c.梗阻类型；d.梗阻是否完全；e.病因
### 单纯性小肠梗阻
梗阻后3~6小时可出现X线表现
- 积液平面超过三个
- 胀气肠曲呈弓形，肠腔气柱渐高征
- 立卧位肠管变化大，短拱形→长管形
- 肠壁、粘膜皱襞一般无明显增厚
- 梗阻点以远肠管萎陷
需注意胀气扩大肠曲涉及的范围、梗阻远侧肠曲有无气体、来估计梗阻位置及是否完全.

### 绞窄性肠梗阻（老师：好像不会考）
原因多为扭转、内疝、套叠、粘连
#### X线表现
- 大多无肠腔气柱渐高征（但偶有）
- 立卧位肠管变化不大，固定
- 假肿瘤征，咖啡豆征，长液面征，空回肠换位
- 肠壁增厚、粘膜皱襞增粗

### 结肠梗阻
原因为结肠癌和乙状结肠扭转
#### X线表现
- 结肠癌所致的肠梗阻
    - 梗阻近段结肠高度扩张、积液
    - 结肠造影检查示不规则充盈缺损
- 乙状结肠扭转：马蹄状扩张的肠袢，直径达10cm，内含大量气体与液体
- 肠曲壁呈三条纵行致密线，向左下方集中结肠造影检查示削尖状、鸟嘴状狭窄

### 麻痹性肠梗阻
原因：急性腹膜炎、脓毒败血症、腹部术后、低钾血症、严重外伤、外伤性休克及腹膜后间隙感染或血肿等 
#### X线表现
- 普遍性胀气，胃、大小肠均受累
- 气多液少呈蜂窝状，液面低
- 肠运动减低
- 短期内复查胀气肠曲多无变化

## 胃肠道异物
不透X线异物、透X线异物

# 食管疾病
## 食管静脉曲张
### 定义
食管粘膜下的静脉丛异常迂曲扩张。绝大多数由门静脉高压引起。
### X线钡餐（首选检查）表现
- 早期：食道下段粘膜皱襞轻度增粗迂曲
- 中期：—食道累及中段，明显增粗迂曲呈串珠状、蚯蚓状，管壁边缘呈锯齿状或多发小圆型充盈缺损
- 晚期：累及上段，管径扩大，蠕动减弱
- 各期：食管壁柔软，与正常组织无明显分界
## 食管贲门失弛缓症
### 病理基础
食管括约肌（包括胃食管前庭段）丧失正常的弛缓能力，引起上方食管的扩大。多见于青壮年，女性多于男性。主要症状：食物咽下不畅，胸骨后梗阻感；后期吞咽困难。
## 食道癌
### 临床特点
好发于40－70岁的男性，早期无症状，中晚期主要症状为**进行性吞咽困难**，可伴有胸骨后灼痛、钝痛。
### X线表现
#### 早期食管癌（了解）
肿瘤仅侵及粘膜和粘膜下层，不伴有淋巴结转移。
- 病变区粘膜皱襞增粗、迂曲、紊乱，边缘毛糙
- 增粗粘膜上的小龛影
- 局限性小充盈缺损
- 管壁略为僵硬，有时伴有轻度痉挛
#### 中晚期食管癌
- 粘膜皱襞消失、中断、破坏，代之以杂乱不规则的影像
- 管腔狭窄
- 管腔充盈缺损
- 管壁僵硬，扩张受限，蠕动减弱甚至消失
- 狭窄段以上食管扩张
- 向食管内外生长可形成纵隔内肿块影
![](/images/yx_xiaohua/中晚期食管癌分类.png)
> 胃贲门失弛缓症只能发生在胃食管前庭段，呈局限性鸟嘴样狭窄，边缘光滑，注意和缩窄型中晚期食管癌区别
> 食道良性肿瘤和食道平滑肌瘤的鉴别诊断：后者病程可较长，且不破坏食道黏膜（“推开”为主）

|  | 食管癌 |  食管静脉曲张 |
| :----------: | :----------: | :----------: |
| 粘膜 | 中断破坏 | 增粗、迂曲、串珠、蚯蚓状 |
| 壁柔软度 | 硬、蠕动消失 | 壁软、伸缩自如 |
| 壁腔 | 狭窄、狭窄上扩张 | 扩张 |
| 分界 | 与正常分界截然 | 无截然分界 |
| 范围 | 较短 | 较长 |
| 钡剂通过 | 障碍 | 顺畅、严重时轻度减慢 |

# 胃肠疾病
## 胃、十二指肠溃疡
### X线表现（胃溃疡）
- 常见位置：胃小弯侧前后壁（胃体下及胃角部）
- 龛影（良性）：边缘光滑突出于胃的轮廓线外
- 龛影口部：
    - （1）粘膜线（1—2mm）：轻微凸起并略向溃疡腔倒卷的肿厚粘膜固有层
    - （2）项圈征（0.5—1cm）：凸起增厚的粘膜固有层和粘膜下层所构成
    - （3）狭颈征（0.5—1cm）：凸起增厚的粘膜固有层和粘膜下层所构成
    - （4）粘膜皱襞集中
- 功能性改变——（1）痉挛性切迹；（2）分泌增加
- 瘢痕性改变，造成胃的变形和狭窄
![](/images/yx_xiaohua/黏膜线项圈征狭颈征.png)

### X线表现（十二指肠溃疡）
十二指肠溃疡
- 90%在球部
- 直接征象
    - 龛影，粘膜皱襞集中
    - 十二指肠球变形
- 间接征象
    - 激惹
    - 幽门痉挛开放延迟
    - 胃张力及蠕动改变
    - 球部固定压痛
## 胃癌
### 临床特点
好发于40—60岁，男性多于女性，早期症状不明显，晚期可出现消瘦、梗阻导致呕吐等等，甚至出现出血、穿孔。
- 早期胃癌：癌组织浸润仅限于胃的粘膜层和粘膜下层，与肿瘤大小、范围，有无淋巴结转移及远处转移无关。
- 进行期胃癌：癌组织浸润超过粘膜下层
### Borrmann分型
I型 肿块型；Ⅱ 型 溃疡型；Ⅲ型 浸润溃疡型；Ⅳ型 浸润型
![](/images/yx_xiaohua/胃癌分型.png)
### 良、恶性溃疡的鉴别诊断
|  | 良性溃疡 | 恶性溃疡 |
| :----------: | :----------: | :----------: |
| 龛影形状 | 圆形或椭圆形 | 不规则、扁平、有尖角 |
| 龛影位置 | 胃腔轮廓外 | 胃腔轮廓内 |
| 龛影大小 | 多小于2cm | 多大于2.5cm |
| 龛影底部 | 较光滑 | 凹凸不平 |
| 龛影边缘 | 光滑、整齐 | 不平整，有颗粒状突起 |
| 龛影口部 | 粘膜水肿，黏膜线、项圈征、狭颈征 | 指压迹样充盈缺损，不规则环堤 |
| 龛影周围黏膜 | 粘膜纠集直达龛影口 | 黏膜皱襞尖端狭窄、中断、增粗、融合 |
| 邻近胃壁 | 柔软，有蠕动波 | 僵硬、平直、蠕动消失 |

## 十二指肠憩室
### 临床特点
一般无症状。部分肠壁局部向外扩张形成的袋状突起，好发于十二指肠降段内侧。
### 造影表现
突出于腔外的圆形或囊袋状影，轮廓光滑，可见十二指肠粘膜伸入其内，可蠕动和排空。
## 结直肠癌
### 临床特点
发生于直肠、乙状结肠，多见于中老年人。临床表现：腹痛、便血、腹部包块。分型与胃癌同。
## 克罗恩病（Crohn's Disease）：不考
### 临床特点
- 病因未明，多见于青年人，女性略多于男性；欧美发病率较我国高。
- 早期可无症状，临床病程缓慢；间歇性腹痛和腹泻，在排气和排便后可缓解为最常见症状。
- 常见并发症有肠梗阻、窦道和瘘管形成、肛门周围或直肠周围脓肿、腹腔脓肿、消化道出血、肠穿孔和癌变。
### 影像学特点
- 全胃肠道节段性、跳跃性分布
- 钡剂检查
    - 早期黏膜"口疮样"溃疡
    - “卵石”状或息肉样充盈缺损
    - 局限性环状狭窄和管状狭窄
- CT/MRI
    - 水成像更好显示肠壁增厚、管腔狭窄
    - 显示腹盆腔并发的脓肿
